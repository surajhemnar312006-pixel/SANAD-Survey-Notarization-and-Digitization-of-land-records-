# SANAD — Roadmap

## MVP Definition
An AI-assisted platform that converts scanned/handwritten land documents into
structured, validated digital records, with human verification for
low-confidence results.

## Phases
- [x] Phase 0 — Setup & Planning
- [ ] Phase 1 — Python Basics & Streamlit Dashboard
- [ ] Phase 2 — Document Image Processing (OpenCV)
- [ ] Phase 3 — OCR Text Extraction (Tesseract)
- [ ] Phase 4 — AI Field Extraction
- [ ] Phase 5 — Database (SQLite) + Auth Roles
- [ ] Phase 6 — Validation, Confidence Scoring & Human Verification
- [ ] Phase 7 — Analytics, GIS, Testing & Deployment
